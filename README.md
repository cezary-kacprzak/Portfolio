## Wykonałem:

Portfolio przygotowane zgodnie z wytycznymi. Portfolio składa się ze strony głównej, strony "O mnie" i strony "Projekty". Na tej ostatniej znajdują się krótkie opisy 3 programów oraz linków do kodu źródłowego. 

Wszystkie strony mają wspólną nawigację, stopkę, zewnętrzny arkusz CSS. Strona dopasowuje się w zależnoscie od szerokości ekranu.

Ponadto, na stronie głównej jako przycisk do ciekawostki umieściłem zdjęcie, co wymagało <img>. W sekcji niespodzianka, po kliknięciu zdjęcia pytanie oraz zdjęcie znikają i zostają zastąpione odpowiedzią, zgodnie z instrukcjami dotyczącymi java script.  

Stronę opublikowałem przez Github Pages z gałęzi main, z głównego katalogu repozytorium. 

Strony sprawdzałem lokalnie podczas tworzenia oraz pod publicznym adresem w oknie incognito:

    - otwieranie stron i działanie nawigacji,
    - linki do kodu programów,
    - działanie interakcji JavaScript,
    - zmianę wyglądu w zależności od szerokości ekranu,
